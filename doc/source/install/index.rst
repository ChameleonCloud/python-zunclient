==================
Installation Guide
==================

This is Chameleon's fork of python-zunclient, published as
``chameleon-zunclient``. It installs the same ``zunclient`` module and ``zun``
command, so don't install it alongside ``python-zunclient``.

At the command line::

    $ pip install chameleon-zunclient

Or, if you have virtualenvwrapper installed::

    $ mkvirtualenv chameleon-zunclient
    $ pip install chameleon-zunclient
